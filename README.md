## 💻 How to Run

### Clone the Repository

```bash
git clone https://github.com/sobitpratel18/dsa-solutions.git
```

### Navigate to the Repository

```bash
cd dsa-solutions
```

### Compile a Program

For example:

```bash
g++ Arrays/linear-search.cpp -o linear-search
```

### Run on Windows

```bash
.\linear-search.exe
```

### Run on Linux/macOS

```bash
./linear-search
```

> Compiled executable files are excluded from this repository using `.gitignore`.
